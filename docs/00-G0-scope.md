## 一句话任务定界

> 在**不登录、不绕过鉴权与人机验证**的前提下，仅依据公开可见页面与正常交互，逆向梳理 `usersearch.ai/m/search` 的页面结构、搜索流程、输入项、结果字段与交互状态；据此用**占位数据与自有界面素材**实现一套功能对齐、品牌与数据完全自有、可本地运行的网站，并交付分析结论与网站实现。

## 授权依据与合规判定

| 项 | 判定 |
|---|---|
| 授权依据 | 用户在本次请求中明确限定：仅使用公开可见页面与正常交互；不复制原站品牌、受保护内容或私有数据；不绕过登录、鉴权或访问限制。复刻对象为**外部可观察行为**，产出为独立实现，不含原站源码、构建产物、素材或数据。 |
| 判定 | **放行（有条件）**。条件：侦察只做公开 GET / 公开索引检索；遇到登录墙、403、人机验证即停止并记为「受限」，不尝试通过、伪造或绕过。 |
| 硬门禁 | 一旦发现某结论需要登录态、私有接口或受保护资源才能验证，立即标注为「未知项·待验证」，不得用猜测填补。 |

## 复刻范围

**做**
- 页面结构：登录入口视图、搜索工作台（搜索类型 → 模块 → 查询输入 → 成本 → 执行）、结果面板、以及可观察的账户/额度相关视图。
- 搜索流程：选择搜索类型 → 选模块 →（可选）配置数据源/过滤器 → 输入查询 → 查看单次成本 → 执行 → 查看结果 → 保存/导出。
- 输入项：查询输入框、搜索类型切换、模块选择、OneScan 多选数据源、Bulk 多输入、过滤器、搜索模式（保留/不保留历史）。
- 结果展示字段：来源归因、匹配状态、Found / Enriched / Connections 计数、置信信号、结果行的标识/来源/状态列。
- 交互状态与边界：初始空状态、加载中、空结果、零结果引导、校验失败、额度不足、数据源故障、搜索卡住/超时、网络异常、批量上限、成本动态变化、分页与导出、结果保存。
- 占位数据 + 自有界面素材，可本地直接运行，附分析结论与交付报告。

**不做**
- 不复制原站品牌名、Logo、配色体系、文案、截图、图标、字体文件或任何受版权保护素材。
- 不复制原站前端源码、构建产物、API 路径、第三方数据源名称与真实价格。
- 不接入原站后端、不调用其接口、不模拟其鉴权、不接触任何真实个人数据。
- 不实现 OSINT 真实检索能力（只做交互与状态对齐的演示）。

## 验收标准

1. 分析结论中每条事实级结论都能指向具体证据（URL / 命令输出 / 公开文档原文），并明确区分「直接证据 / 公开资料佐证 / 推断·待验证」。
2. 网站覆盖上述「已识别的核心页面、交互与状态」，每一个状态都有可复现的触发路径。
3. 网站在无网络、无后端、无构建工具的情况下可直接打开运行；关键路径有一轮自动化自测输出。
4. 网站中不含原站品牌、受保护内容、真实个人信息或私有数据；所有结果为占位/合成数据。
5. 独立验证员出具分级差异报告，阻断级差异清零或明确列为不可交付项；最终报告逐条给出 G0–G5 门禁结论与合规声明。
