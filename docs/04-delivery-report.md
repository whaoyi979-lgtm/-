## 1. 这次复刻了什么

### 1.1 路线声明（决定验收口径）

参考目标 `https://usersearch.ai/m/search` **位于登录墙之后**，且 `curl` 朴素 GET 返回 403 Cloudflare 质询页。按用户给定的硬边界（仅公开可见页面与正常交互、不绕过登录/鉴权/访问限制），本次**没有**取得目标页的一手 DOM、脚本、接口与截图。

因此交付的是：**以同品牌官方公开文档中逐字描述的行为规格为输入，重建的一套功能与交互状态对齐、品牌与数据完全自有的演示网站**。它对齐的是「点击后发生什么」，**不对齐**像素、源码与网络请求；所有结果数据为合成占位。

### 1.2 页面清单

| 页面 | 路由 | 内容 |
|---|---|---|
| 登录入口 | `#/signin` | 页头（品牌/支持/主题切换/加入）、主卡片（邮箱/密码/忘记密码/记住登录/主按钮/分隔/邮件登录/第三方登录）、页脚（注册/隐私/条款/DPA/合规/版权）；纯前端演示会话 |
| 重置密码 | `#/reset` | 邮箱输入 + 发送验证码（不提交外部服务） |
| 检索工作台 | `#/search` | 顶栏（状态指示、额度、Case、模式、视图分段）、左导航（搜索类型）、查询构成区（模块卡网格、描述面板、输入框、成本行、批量、配置弹窗、实体类型页签）、结果面板（双 tab、三计数、动作区、结果表、详情 tab） |
| 额度页 | `#/credits` | 余额、充值面板（预设/滑块/单次或周期/确认）、交易记录表 |
| 留存页 | `#/cases` | Case 列表、书签、搜索历史（保留/隐私模式差异） |

### 1.3 交互与状态清单

- 主流程：选搜索类型 → 选模块（成本类型 免费/固定/浮动）→ 配置数据源与过滤器 → 输入查询并核对单次成本 → 执行 → 复核结果 → 书签/导出/以线索再查。
- 组合维度：多源扫描（1 输入 × N 来源，成本求和）、批量查询（≤5 输入 × 1 模块，成本累加）、两者叠加。
- 模式与留存：保留模式写历史 / 隐私模式不写；Case、书签、交易记录。
- 状态：初始空态、加载中（结果逐行流入、可取消）、成功、零命中（明确「结果不是错误」+ 引导）、关联线索为空（口径差异）、部分来源故障、输入校验失败、额度不足、批量超限、超时/卡住、网络异常、会话失效、导出。每个状态可经界面「状态演练」或 `?state=` 一键复现。
- 边界：空值/纯空格/前后空格/完整 URL/超长/特殊字符/中文 emoji、余额临界、数据源全关、过滤器全收紧、分页末页、批量 1/5/6 条。

> 详细规格见 `docs/01-blueprint.md` §3–§8、验证清单见 `docs/02-verification-plan.md`。实际实现与自测结论以 `[待回填：站点与自测]` 为准。

### 1.4 关键实现说明

- 纯静态 HTML/CSS/JS，传统 `<script src>` + UMD 风格全局导出，零第三方依赖、零构建、零外部请求；`file://` 双击可运行。
- `data.js` 只放合成占位数据；`core.js` 为不碰 DOM 的确定性纯函数（校验、成本、状态机、结果组装、分页、额度、CSV、模式）；`app.js` 负责渲染与编排。
- 自有品牌「观澜」，靛蓝 + 石板灰，浅色主题（可切换深色），内联 SVG 图标，系统字体栈；工具型界面有列头、字重分级、实心状态标签。
- 移动端优先 + 桌面自适应（针对 H-13 `/m/` 可能为移动版的范围风险）。
